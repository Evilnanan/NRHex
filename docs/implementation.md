# 当前实现入口

本页列出当前源码与配置入口。版本变更集中在 [历史变更](../CHANGELOG.md)，原生依据保留在各主题研究文档。

- 亮剑蓄力增伤（0.17.231）：`sword.rs::add_melee_category`在原生110存在时追加100，沿既有攻击倍率缓存前／命中结算前入口应用；`extra_melee_application`只为同时有130、110、100且筛选100的失败法术查询开放武器副本重试。保留原有110与正常查询优先，避免丢失或重复蓄力法术加成。原生重力球47200无蓄力分类、47205带110；武器8320100／1／2分别为16%／19%／22%。详见[蓄力增伤核对](research/sword-charged-damage.md)。

- 圆桌重载清理（0.17.227）：`HexBuild/HubCleanup.cs`统一补齐旧海克斯的拥有状态、所属私有效果与痛饮独立层数清理。只在common事件9100941的原有地图10／11进入守卫内执行一次，再等待离开圆桌；圆桌／训练场重载会重新执行，停留期间领取能力不被循环清除。保留既有重置通知及新海克斯清理，不改变出征事件1111或倒地／复活行为。全量构建与`--hub-cleanup-stage`共用逻辑，检查原有指令可逆还原、无关事件逐项一致、重复执行不重复插入及地图守卫失配拒绝。只清理本机角色上的私有SpEffect，不批量删除原生道具或原生效果。

- 别停止咏唱（0.17.219）：魔法、祷告正常完成蓄力时一次回复30点精力，撤掉旧按秒恢复；在原生取消检查后的施法回调确认蓄力窗口结束，提前松手／中断不返还。复用野兽的捕猎瞬时回精力视觉，不附带原生增益，详见[完成蓄力实现](research/chant-completion.md)。

- 回响“火焰啊”（0.17.218）：Magic6001普通／蓄力根使用与两种兽爪相同的独立原生整次施法命中记录；不再沿用首发已命中目标，但同轮回响内部仍共享去重，延迟保持0.5秒。针对同敌人无法再次命中的修复待实机验收，详见[回响施放](research/echo-cast.md)。

- 亮剑回收状态生命周期（0.17.217）：`update_sword` 不再因 HP 归零主动删除承载 state449 的95000912；原生删除后，倒地／复活过程中不补加，正常恢复后再补齐，失去亮剑时仍明确移除。施法减伤、强韧和旧手部视觉继续独立清理，并采用原生倒地／复活标志判断不可施法状态。不改回收公式、额度、时间窗口或 HUD；针对死亡长血条的试修仍需实机验收，详见[只读调查](research/sword-regain-hud.md)。

## 构建参数包

群友版打包启用ME3的`disable_arxan = true`保护原生钩子，与测试热键是否编译无关。故障现场DLL初始化成功且ACTIVE=1，但主更新入口恢复原版代码，出征标记存在而2级奖励不发；仅启用中和并重启，同一DLL的27处抽查入口恢复有效。该对照支持运行期代码还原，而非启动签名失配；不据此推断所有历史运行均会失败。在线设置、重定向与其他Mod不随之改变；日志和ACTIVE值必须结合实际入口字节检查，不能单独作为玩法已工作的证明。

重启后的同一出征现场捕获2级达成95001010、发放95001000及三项私人奖励节点；用户确认奖励出现。仅验收该次升级发奖，不代表全部能力或联机通过。

`HexBuild/RegulationCompression.cs` 固定使用 `DCX_DFLT_10000_44_9`，全量构建和末尾回读检查共用该格式。重新压缩时比较完整未压缩 BND 和每个成员的字节、名称、编号、标志，确保玩法数据不变；不要将大型参数包重新改为 ZSTD。启动加载验证与海克斯实战验证分别记录。
