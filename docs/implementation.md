# 当前实现入口

本页列出当前源码与配置入口。版本变更集中在 [历史变更](../CHANGELOG.md)，原生依据保留在各主题研究文档。

## 构建参数包

群友版打包启用ME3的`disable_arxan = true`保护原生钩子，与测试热键是否编译无关。故障现场DLL初始化成功且ACTIVE=1，但主更新入口恢复原版代码，出征标记存在而2级奖励不发；仅启用中和并重启，同一DLL的27处抽查入口恢复有效。该对照支持运行期代码还原，而非启动签名失配；不据此推断所有历史运行均会失败。在线设置、重定向与其他Mod不随之改变；日志和ACTIVE值必须结合实际入口字节检查，不能单独作为玩法已工作的证明。

重启后的同一出征现场捕获2级达成95001010、发放95001000及三项私人奖励节点；用户确认奖励出现。仅验收该次升级发奖，不代表全部能力或联机通过。

`HexBuild/RegulationCompression.cs` 固定使用 `DCX_DFLT_10000_44_9`，全量构建和末尾回读检查共用该格式。重新压缩时比较完整未压缩 BND 和每个成员的字节、名称、编号、标志，确保玩法数据不变；不要将大型参数包重新改为 ZSTD。启动加载验证与海克斯实战验证分别记录。

## 交锋

抽取排除隐士（7）与复仇者（6），由 `reward_choices::role_exclusions` 统一处理，正常抽取、测试发球及逐栏刷新共用；轮换池重置不绕过角色限制。

攻击窗口、命中结算、连续招架和转向均要求原生判定未腾空。调用物理模块的4678E0查询：当前接地标志+92为零、475810跳跃控制判定为真、或动作模块+58的bit55为真时禁止触发；不依赖普通跳劈的分类102，因此跃起战技也使用同一判定。起跳当帧残留的私有TAE防御标记在本次命中结算范围内撤销并恢复，普通原生防御不受影响。防御成功前已获得的反击增伤不因腾空直接删除。隔离测试执行原生查询，覆盖接地、跳跃控制和动作标志的8种组合；视觉上离地但原生未标记腾空的特殊动作仍需实机排查。
