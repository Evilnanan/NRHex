# 玻璃大炮：来源专属防御穿透

当前EXE SHA-256：`9545e8732919bb6a63904cb73223641b3c4f9a67869be5722612acca413e8b3a`。参数持有标记95000300，五种AttackRate由1.4改1.2；五种AttackPowerRate保持1，八种DamageCutRate保持10。

## 原生结算证据

`43D2BF`把来源转换为ChrIns或零；`43D4BE`把该实际攻击者传入通用受击计算`439E80`。这涵盖原生弹丸归属者，也不会把弹丸对象解释为角色。`439E80`先于玩家/NPC接收分支执行。线程局部栈保存本次攻击者是否持有玻璃大炮及目标效果管理器，嵌套受击不继承外层资格。

`6C5FC0`实际ABI为八个指针、七个栈上传递的float，返回XMM0中的float。前两个输入数组是基础伤害及攻击者倍率；后五个为目标特殊效果、装备/模型抗性、盾牌格挡及两组条件效果系数。所有数组按物理、魔力、火、雷、圣五种分量组织。EnemyIns虚表`2C16F10 +3D8`指向`4DA660`，该函数直接取NpcParam `1A4～1C0`的模型抗性；玩家装备通过`6695A0→6CCD70`汇总。

穿透时使用私有数组替换接收者系数：`503800`按普通效果、类别110、类别434分别汇总同一组`DamageCutRate`字段，合成函数的`effects`、`conditional`、`additional`参数对应这三组。0.17.206起，将装备／模型抗性与这三组效果按物理、魔力、火、雷、圣分别相乘，再取与1的较大值，保留最终净负抗性／减伤；例如最终30%抗性按1倍承伤，最终−30%抗性保留1.3倍承伤。先合并再限幅，基础正抗性可以抵消效果负抗性，反向组合也一样；不逐层单独保留增伤。盾牌格挡仍中性化，即使它大于1也不保留。并取消弹刀伤害系数、弹刀比较结果及目标状态2120的额外系数。保留基础伤害、攻击者倍率、招式倍率、重复命中及位置修正和攻击行自身平衡系数，再调用原生合成函数，保留各分量输出与总伤害。没有最后把HP伤害强行写回的自定义公式。

另一个目标防御入口`506700`在合成前把目标的`defObjectAttackPowerRate`（SpEffectParam偏移318）乘入基础分量。仅当本次攻击具有穿透且查询的是这次目标的效果管理器时，将查询结果中性化为1；攻击者自身或其他目标的查询保留。原查询照常执行。

原生碰撞无敌、命中取消与后续受击有效性检查保留。异常积累和独立异常持续伤害不走这五种普通攻击分量，因此本实现不修改异常抗性或异常伤害。敌人阶段转换、脚本处理和联机实际覆盖仍需实测；隔离验证不等于游戏验收。
