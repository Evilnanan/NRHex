# 风暴管束者场外特效（0.17.57）

用户报告百般武艺重铸出的风暴管束者有实际攻击效果但没有视觉，怀疑原生只在永夜征兆场地显示。本轮未改变战技动作、伤害、状态条件或重铸规则。

原生 SwordArtsParam 1200 对应动作类型 260，c0000 的 a860.tae 直接使用 450954～450957 等特效；部分攻击子弹使用 450951、450961～450965。450954 的动画事件带 stateInfo 2348 条件（对应原生 SpEffect 604205）；该条件保留。带条件的视觉与资源加载是两个不同问题，不能一概移除状态条件。

读取当前游戏原始资源确认：风暴管束者这组 450940～450965 共 17 个 FXR 在征兆的 `sfxbnd_c7540.ffxbnd.dcx` 中，原始 `sfxbnd_commoneffects.ffxbnd.dcx` 与 common DLC 包没有它们。这个资源分布可以解释“场外有攻击却不见风”的现象；并不能证明官方设计意图。

读取 data0 时发现 DSAS 缓存时间戳不匹配，未绕过缓存检查。改用本机 Smithbox 的 Nightreign 原生资源解密实现，从当前 data0.bhd 重新解密目录，选择性读取原始 BDT 的通用与征兆特效包；没有更改游戏安装文件或旧缓存。

补丁将这 17 个原生 FXR 和对应 ffxreslist 加入通用包，按资源清单解析纹理与模型依赖：通用包已有的依赖复用，缺少的从征兆包复制。资源内容保持原字节，文件 ID 按原生 FXR／纹理／模型／清单类别分配，不碰原有 ID。原生征兆特效包仍保持原样。

生成后重新读取整个通用包，比较全部原生成员 ID、名称、标记及内容，校验新增资源与原始征兆包逐字节一致、依赖齐全以及容器格式一致。详细结果在 `storm-vfx-validation.json`。构建入口为 `HexBuild --storm-vfx-stage`，研究提取为 `--storm-extract`，原输入位于 `.work/storm-vfx-01757/extracted/sfx`。

交付与上一版0.17.56待更新内容合并，保留收集白雾改到自身的实现。启动脚本支持为新增资源创建目标子目录，仍先校验全部待更新文件。单人场外蓄力、挥斩、弹体与命中显示以及双方联机显示均待实机测试。
