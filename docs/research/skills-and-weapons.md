# 战技与武器实例

## 重铸在实例查询层实现

保留原生库存数据，以本地武器实例的完整 handle（含代际）维护原生战技和当前随机战技。查询战技 ID／动画类型／参数时，仅为本地持有海克斯的武器提供覆盖；不要修改共享 `EquipParamWeapon`，也不要把所有同名武器归成一个实例。

当前海克斯拥有者为 95001400；脚本使用精确 f32 标记 6999800～6999803。HKS 区分真实出招、动作链忙碌及左右手通知，退出整条动作链并经过两个安静更新后才重铸。架势准备不算使用，真实攻击架势循环要算使用；旋转刺轮等能持续移动的战技不能只靠常规结束回调判断。

原生战技为风暴管束者 1200 或小圆盾格挡 303 的武器受保护；普通武器随机到这些战技仍可继续重铸。正式名称从中英文 `ArtsName` FMG 交叉核对，不用参数行别名代替游戏名称。无战技 1／10、空技能、未知占位和火把攻击 117 排除。火把攻击动画类型 17 在原生右手／双手入口被拒绝，左手专用路径不是任意武器都能使用。

`data/reference/actions/swordarts-enable.lua` 保留原始 `assets/original/action/script/c0000.hks` 的函数 49 `IsEnableSwordArts`，供 `verify_arts_constraints.py` 核对动画类型 17 的禁用条件，不作为游戏脚本加载。已用 DSLuaDecompiler 独立反编译并逐字核对；清单哈希对应 `.gitattributes` 规定的 UTF-8／LF 文件，旧 CRLF 表示的哈希不适用于仓库中的 LF 文件。

当前 182 种技能分为 175 种普通池和 7 种弓池。短弓、长弓、大弓按原版 `wepType` 50／51／53 分类；弓战技通过原生演武武器类型识别。弩和弩炮当前仍属普通池。名称存在、动画存在或通过静态检查，不保证每个随机构型都可实战工作。

## 专用行为与子弹

更换技能 ID 只切换动画；动画中的 judge ID 还会结合当前武器 `behaviorVariationId` 查攻击／子弹行。专用战技换到其他武器后“空有动作”，通常需要追踪这层来源。

原生 `SwordArtsParam.sparringGroundsWeaponId → EquipParamWeapon.behaviorVariationId` 给出每个战技的演武来源。当前解析器在本地指定技能的 judge 范围 3000～4000 中，按该来源查 `BehaviorParam_PC`：

```text
映射行 ID = 300000000 + 原生 variation × 1000 + judge % 1000
```

只使用实际存在的原生行为行，查不到时原样返回原生结果；普通攻击不改。来源武器 handle 和 base ID 使用同一个原生 source decoder，包含左手和双手握持，不能用“当前右手”代替此次实际来源。

通用行为映射解决了两种星云等专用参数依赖，但模型发射点是另一层。火焰唾球 1001 的原生盾牌炮口为 10141／20141，火焰舌柱 1002 为 10142／20142。其他武器缺少这些挂点。当前仅在本地拥有者、随机到对应技能、对应专用行为来源的调用中，将私有发射描述符的挂点改为角色通用 58；原生火焰盾保持原挂点，子弹和伤害参数不变。这项已通过 ABI／范围检查，实际视觉与命中仍需用户测试。

## 丢弃与捡回

原生掉落会创建新的物品实例，原库存 handle 不能作为捡回身份。当前方案用原生地上奖励的唯一编号将丢出实例与新实例连接：奖励描述符大小 0xC0，UID 位于 +0x5C，武器 payload 为 0x48 字节。

丢出时记录实例的原生战技和当前覆盖值，地上、网络及库存 payload 保持原生；本人拾取同 UID 后，在新 handle 建立原覆盖。两个相同武器按独立 UID 关联。普通丢弃、拾取替换自动丢弃、联机延迟生成队列都要覆盖。嵌套原生调用以 TLS 范围和 RAII 恢复上下文，不能让拾取中的自动丢弃覆盖外层拾取 UID。

来源验证见 `verify_arts_behavior.py`；丢拾链见 `verify_arts_transfer.py`；可用／弓分类和发射点见 `verify_arts_constraints.py`；真实动作通知见 `verify_arts.py`。静态和隔离测试不能替代逐项游戏测试。

## 专用模型与属性伤害

毒蛇咬杀1007的AtkParam_Pc 303020900/901依赖141～144等盘蛇盾蛇身模型挂点；随机池排除1007，原生EquipParamWeapon 30200000及战技、攻击、模型保持不变。生成器保留武器默认战技映射，只从候选技能与随机行为映射中排除它。

掠夺火焰弹丸2030～2033引用300314902，火属性补正510、基础固定火攻击0；家族冤魂2020～2025对应301302900～905，魔力补正200／135／145、基础固定魔力攻击0。它们依赖来源武器对应属性，未提供对应属性时弹丸可以为零伤害；掠夺火焰挥砍300314905/906是独立的全属性武器攻击。按用户要求保留原生伤害计算，不替换伤害来源、不增加补偿值。原生参数调查位于.work/arts-combat/native.json。
