# 回响施放（0.17.173）

95003500。文案：魔法、祷告专注值消耗提升125%，施放后额外产生一次弹体。仅女爵（4）、复仇者（6）、隐士（7）可进入普通抽取、定向补位和逐栏刷新；失配或未准备角色不提供。

## 支持范围

基于原始regulation 10350000（SHA256 876A3CA279A4561D0C69F81FE5E510C75C59AB9A8A201694F8CF4A42C91E0268），读取160种普通魔法／祷告的Magic引用。首版保留50种法术的79条根弹体，0.17.171适配11种群体辅助，0.17.172再增加44种法术的136条根发射，0.17.173单独适配两种陨石的12条根生成。当前静态目录共107种配置、238条根发射，其中105种／226条仍延迟0.5秒回响，两种陨石即时追加一次原生随机生成。帚星4021的普通10402100和蓄力10402150都包含。不是每颗后续子弹再回响：仅原始Magic引用的实际根发射处理一次，命中分裂和爆炸交给原生链；重复施放和一组多弹体继续使用原生发射次数、散布和后续链。

按用户约定，仅自身的治疗、增益和附魔不回响，攻击法术不按单体／群体排除。除两种陨石的专门适配外，菜单具有循环消耗的法术、跟随角色／挂点的根弹体、生命周期不定的根弹体继续排除；熔岩吐息7010、席欧朵利克的熔岩7011、普拉顿桑克斯的凋亡7050待单独适配，火焰重罪7900作为个人增益排除，避免把后续周期伤害当成多次施法。延迟攻击根发射包含多个独立目标描述符、或依赖额外父对象指针时不登记；专用群体范围效果和即时陨石不依赖目标描述符个数，陨石仍排除带父对象指针的发射。

延迟目录根筛选条件为Magic普通编号4000～7999、consumeLoopMP_forMenu<0；Bullet寿命>0、FollowType=0、isSyncBulletCulcDumypolyPos=0。原始字段子集保存在data/reference/combat/echo-cast.json。consumeType枚举0／1／2分别是Default／Charged／None；2不是持续施法，而是无消耗，可用于侧向发射、辅助或额外SpEffect。首版据此排除整种法术是错误的。0.17.172沿固定SHA256的data/reference/combat/sword-graph.json中HitBulletID、intervalCreateBulletId和AtkParam_Pc遍历：新放开的引用必须能到达具有五属性攻击、削韧或攻击反应字段的弹体，排除空控制弹体和个人恢复效果。原有独立发射目录保留；群体辅助使用专门配置。tools/build_echo_cast.py生成并检查src/echo_cast_data.rs，可输出目录报告，验证器从报告读取数量，避免手工计数过时。原生Magic和Bullet行均不修改。

## 陨石密度翻倍（0.17.173）

陨石4700、艾丝缇陨石4701分别从原生Magic的Bullet引用生成独立DENSITY目录，不进入延迟队列。两者均有循环消耗；每种6条根必须满足有限寿命、无跟随、无同步挂点，并沿原生子弹链到达攻击弹体。

| Magic | 即时追加的根Bullet |
| --- | --- |
| 4700 | 10470000、10470005、10470010、10470020、10470030、10470040 |
| 4701 | 10470100、10470110、10470120、10470150、10470151、10470152 |

每次符合拥有、存活、本机来源、法术行为和无父指针条件的实际根发射，先执行一次原35A460。它返回输出指针，不能用返回值非空判断成功；仅输出句柄不为-1时，用同一帧、调用者仍持有的原描述符立即再调用一次35A460，额外调用使用独立的输出句柄和错误码。原发射失败不追加，追加失败不改写原成功结果，也不跨帧重试。不重播施法动作，不额外扣FP，不改描述符或网络标志。

两次原生计算各自生成随机参数，后续天空／地面位置、计时生产、石块飞行和落地爆炸沿原生链执行；不保存每颗石块位置，也不复制延迟快照。12条原生根的createLimitGroupId均为0。辅助节点、石块和爆炸不在DENSITY目录，避免整条链递归翻倍。同步生成期间用TLS标记阻止嵌套发射再次放大，并清空延迟捕获范围；没有新增跨帧引用或队列记录。原生网络位保留，两次成功各自沿原生网络分支入队，实际主客机传输仍待验收。

## 原生发射与目标

35A460是原生BulletMan根发射入口，4B77C0的角色发射器调用它。35A460先用33D010计算包含目标的发射数据，再调用35DA70分配弹体，最后沿原生网络队列发送。

hook 35A460只为本机存活拥有者、角色来源句柄匹配、行为编号<0、Magic与直接Bullet编号匹配目录的根发射建立TLS范围。35DA70在该范围捕获首次计算结果；同一范围的后续／嵌套工厂调用不再捕获。分配返回空时立即释放副本，不登记回响。

延迟记录复制0x110字节发射描述符及计算后完整世界姿态。攻击的目标从计算后数据+148／+150中的唯一0x50字节目标描述符取得，使用原生3482E0复制并保留目标引用；群体范围副本清空实体目标。两者的输入+98／+A0原生引用均按原生掩码保留；完成或取消后统一调用33E650释放，内部继续用3482B0和原生引用计数原子操作。重放替换目标时，3482E0同时释放重算阶段临时保留的新目标引用并保留原始引用，待原生释放发射数据后恢复平衡。不会把临时TAE数据或目标裸指针放入跨帧队列。

在游戏Update按dt推进0.5秒后，直接调用原35A460重放，保留法术、蓄力版本、来源、姿态、倍率字段及网络位；新增独立发射位。玩家移动、切锁或原输入缓冲区复用不能改写快照。攻击实体目标仍有效时沿同一个原生目标描述符发射；失效时取消该次，不让引擎自动重新选择其他目标。无锁定攻击恢复原生已解析的瞄准描述符，群体范围副本不检查敌人目标存活。回响不再次登记回响，不重播施法动作或再次扣FP。

角色／属性／句柄／远征上下文变化、倒地／死亡或失去能力时丢弃待发记录。释放和发射均在游戏回调线程、状态锁外执行。一次原始根发射一条待发记录，未添加隐藏命中或施法冷却。
