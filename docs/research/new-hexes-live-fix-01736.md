# 两个新海克斯现场诊断（0.17.36）

2026-10-11，用户在复仇者远征内测试，加载的确为 dist 中的 0.17.35，两个拥有效果及动作脚本标记均存在。只读诊断没有注入、修改运行中游戏或终止进程。原生 EXE 指纹沿用现有完整哈希门禁。

## 强化【召唤灵魂】

现场保留的原生龙装大树守卫 HP 为 0，NpcParam 32500090，NpcThinkParam 32500010，模型编号 3250。击杀者句柄与本地玩家一致，灵魂状态却为空。旧代码错误地把虚函数 +190 返回值当作 AI 数据；实际上是 PlayerGameData 的回退对象，现场 +868、+E8 均为 -1，随后被旧的非负值检查拒绝。

原生 391DC0 组装三个整数：actor +68 的 NPC 行、虚函数 +1A8 返回的 Think 行、仅 PC 才读取的 CharaInit 行。普通 NPC 的第三项应为 -1。旧实现同时把第一项称作模型，并把私有 NPC 放在第二项，模拟测试重复了这个错误约定，没有发现问题。

本次改正为 `[privateNpc, sourceThink, -1]`，并同步修正 3918D0 的创建参数和 1Bh 消息中偏移 12／16／20 的三个字段。正常 NPC 不再调用 PlayerGameData。新增测试使用现场三个互不相同的编号，禁用错误的 +190 getter，并验证先空召回再击杀仍可记录、第三项 -1 可保留、网络载荷字节顺序正确。

## 气球

第一次快照已有 750 的自爆伤害记录，证明触发请求被处理。随后用户再次阵亡并反馈无特效、伤害及冲击力；只读监测捕获 HP 0 时 95001701 成功加入，首帧节点 flags=4，后续 flags=8，约一秒后消失。

原生 3E0E30 在 427260 判定死亡时跳过 50AA20；后者才会消费 stateInfo 275 的首帧标记并调用 397570 → 3975D0 发射。因此允许效果作用于死者、延长效果寿命都不能解决死亡后不执行发射更新的问题。

现在直接调用已经有签名门禁的 3975D0，使用 50AA20／396AE0 的原生描述符（挂点 85、模式 2，其他默认值保留）及相同来源参数，发射独立行为 950017000。不再额外施加 95001701，避免濒死更新和直接发射各触发一次。保留最大 HP 快照、7 号冲击力、敌我命中规则、一次倒地只触发一次和复活重置。没有修改角色阵营、HP、救援状态或全局命中规则。

参数、HKS、文本、刷怪笼与百般武艺均未在此次修复中重建。此次只修复已定位的发射阻断；濒死来源的实际碰撞／命中是否仍被其他原生检查阻止，需要实机确认，不能以调用发射函数的模拟测试代替伤害验收。
