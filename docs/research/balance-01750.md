# 0.17.50：气球图标、灵魂优先级与亮剑减伤

气球复用吵闹鬼的原生图标：PermanentBuffParam 21229、SpEffectParam 与 AttachEffectParam 22229、EquipParamGoods 20229。仅修改气球对应的四个图标字段，回读验证其他行、字段和参数表保持不变。

强化【死灵术】在有效团队击杀回调中，从被击败角色的 ChrStatsModule +0x144 读取实际最大 HP，保存数值而不保留角色指针。仅在无储存灵魂或新强敌最大 HP 更高时接纳；相等保留旧灵魂，非正值不接纳。实际最大 HP 包括当时游戏已经应用的血量修正，不按 NpcParam 的基础血量或尸体剩余血量比较。只有接纳时才安排尸体收集白雾。

召唤成功会消费灵魂并清空优先级；失败重试保留储存值。仍可在当前灵魂作战时收集下一只。原生槽位退场判断、落点选择、每秒 1/60 掉血和 25% 输出倍率保持不变。优先级覆盖全部符合收集条件的独立单位。

亮剑咏唱减伤采用用户指定的承伤率：`x = 表中加成 * 0.01`，`y = 21*(1+x)/(40*x*x+81*x+21)`。在原有受击结算点乘以 y 后向下取整；不改变触发条件、表中数值、增伤或 1.5 倍吸血。加成 25%、50%、100% 时减伤分别为 40%、约 55.94%、约 70.42%。零或负伤害保持原值。

检查覆盖灵魂的较低／相等／较高最大 HP、收集特效、失败重试、成功消费后重新收集，以及减伤公式参考点和单调性。共 212 项 Rust 测试、91 处原生签名与参数／文本回读检查通过；实际游戏表现待验证。本轮不启动游戏。
