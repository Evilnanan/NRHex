# MMV 战技移动施放修复

MMV 原始 `c0000.hks` 的 `ExecAttack` 右手普通战技入口仅在
`c_SwordArtsID == 328`（艾珀莉亚漩涡）时执行上半身混合动作，其余使用
`W_SwordArtsOneShot` 全身动作。原生字节码此处调用 `IsHalfBlendArts`，
MMV 的同名名单也仍然包含转啊转（动作类型 20）及家族怨魂（184）。
读取原版、原 MMV 和本地合并版参数确认，两者的战技参数 ID 分别为 120、1184，
动作类型没有变化；隔离执行原 MMV 和合并版右手分支均复现了错误路由。

合并器通过 `compat/mmv/hks-interior.json` 的 `sourceFixes` 恢复此处
`IsHalfBlendArts(c_SwordArtsID) == TRUE` 判断。整个原函数的 SHA256 与替换锚点
共同保护补丁，源版本变化时停止构建并要求重新审核。该修改纳入合并器的精确逆操作检查，
不改左手、共持入口、名单、耗蓝、动作取消或持续施放逻辑，也不改外部 MMV 输入。

验证：完整合并生成 174 个适配函数并通过 Lua 5.1 语法及逆操作检查；
5 项 HKS 测试通过，其中移动施放测试覆盖 4008 个动作类型、武器类别和混合模式组合，
同时验证原始回归、艾珀莉亚漩涡及普通站桩战技的路由，以及源函数漂移时拒绝修改。
本地 MMV 脚本仅应用同一条件替换，并完成输出回读和逆操作验证。
这些是脚本隔离测试；游戏内移动、连续施放及联机仍需实测。
