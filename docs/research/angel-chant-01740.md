# 天使的添翼、别停止咏唱（0.17.40）

实现依据为本机原始 EXE、regulation、c0000.hks 和 c0000.anibnd；没有启动或连接游戏进程。EXE SHA256 为 `9545e8732919bb6a63904cb73223641b3c4f9a67869be5722612acca413e8b3a`。

## 天使的添翼

拥有行95001900。原生参考7037800使用stateInfo2130，成功后写入伤害描述符+0x2c3的位2；43D5EE随后读取PlayerCommonParam+0x2e0的7037805并执行原生失效反馈。该位置也是结晶外壳已使用的入口。

在已有伤害完成回调中，记录本地角色对存活对象的有效正伤害命中，排除自己和已失效的攻击；开启1/15秒游戏时间窗口。后续有效命中重新计时，窗口内可使多次敌方攻击失效。收到攻击时保留原生的特殊伤害、忽略失效和已失效标志检查；排除无角色来源的环境伤害、自伤、濒死和死亡状态。优先处理天使，再处理结晶外壳，避免双重消耗。攻击没有命中则不开窗；原生不可失效的攻击仍保持其规则。时间按角色更新帧推进，分辨率受游戏更新频率限制。

## 别停止咏唱

拥有行95002000；抽取和实际激活均要求原生英雄ID4、6、7（女爵、复仇者、隐士）。6999920是隐藏启用标记，6999921是单次蓄力通知，无可见HUD条目，不复制其他海克斯的可用状态。

原生HKS的MagicFireRight/Left及第二、第三段更新共6个函数，在100610存在时检查施法键是否仍按住、是否允许继续施法；松手、条件不满足及动作中断会提前返回。补丁插入这些判断之后，另要求IsChargeMagic、非CheckIfHoldMagic、IndexMagicSlot不为2。普通起手、取消／恢复阶段、持续喷射循环、法术类战技没有回复入口。左右手、第二施法槽及原有百般武艺／亮出你的剑的脚本段保持原逻辑。

Magic4021帚星的stamina=35、stamina_charge=46、refType=2，对应a402。首发45010的100610区间为0至20/30秒，因此基础速率46/(20/30)=69点/秒。只在实际蓄力回调发生时消费当前角色更新帧的回复预算，同一帧去重，保留不足一点的余数；停用、死亡、对象切换和间断清除余数，满精力时不储存溢出回复。

原生act1001在3F6302调用4261D0(stats, signed_integer, false)，最终由427F00限制当前精力至上限。直接每帧传浮点会被截断，因此由Rust累计小数再调用同一原生入口，不直接写精力内存。

69点/秒是按原始首发蓄力窗口校准的暂定值，并非完成施法后返还固定46点。起始精力已满时会受到上限截断；连段动画、施法速度和其他精力效果可能改变实际收支，须实机测试，未宣称所有配置绝对零消耗。a402的后续45020/45030蓄力窗口与首发不同，仍沿用统一速率。
