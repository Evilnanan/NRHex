# MMV 百般武艺适配

2026-10-26；Mayhem Augments 0.17.254。本轮更新 MMV 测试版 DLL 和 HKS；原MMV、参数包、配置、独立版及群友版保持原状。

## 武器与随机池

目标表重新读取合并参数的全部2619条武器记录，其中新增302条，包含属性变体、入侵者及道具载体，不是302把不同的可用武器。默认战技按每件武器参数识别，不再需要实例已经写有覆盖值才能处理新武器。

新增弓7230000、41071000、41080000、41081000纳入原生弓类50／51／53，仍只使用7种弓战技。火属性资格新增57条，魔力属性资格新增74条（73条新武器，另1条已有武器的目标面板变化）；吞世、掠夺火焰、家族怨魂继续按实际面板检查。原风暴管束者、小圆盾格挡保护不变。

新增战技并非全部可以跨武器重铸。本轮逐项登记104条新记录，37条具有独立可用入口和完整公共攻击记录，加入普通池，普通池175→212，弓池仍7。其余67条暂不随机，包括连段内部、无动作或不可用记录，也包括待单独处理的专用模型、成对动作、武器行为、弹药或充能依赖。这些排除项只影响新随机结果，不删除MMV原装备战技；其原有施放和使用通知流程继续保留。

## 攻击路由与动作通知

原有攻击重定向只识别judge3000–3999，而新招式大量使用2000、6000、7000段。仅扩大数值范围会误把普通攻击映射到错误武器行为；本轮为37种已审查战技，从其TAE的攻击／弹体事件生成241项精确的 `(战技, judge, 公共Behavior ID)` 映射。只有清单中的匹配返回目标，其他情况走原生；原版战技保留其原有武器行为变体路径。原生解析仍先执行，ABI及其副作用保持。

MMV新增的双手／左手反击、双手单发盾技、持续循环及梅瑟莫连段节点补充“已使用”通知；循环结束和翻滚衔接节点只维持忙碌，不凭后摇或移动本身制造使用记录。总计7处新增前缀。所有通知仍受6999800拥有标志保护，使用c_SwordArtsHand选择来源，实际处理保持本机拥有者过滤。完整原函数哈希固定，合并逆操作还原原MMV每个字节，原返回／状态转移不变。

装备覆盖仍以实例handle／原战技／基础武器识别，连续攻击结束后重铸，丢捡按地面UID恢复。联机沿用已修正的原生玩家0x0C装备快照；新战技通过同一快照字段传递，同版本双方从同一目标映射解析攻击。未新增协议，也没有回退为仅同步物品栏预览。

## 可重复构建及验证

- `tools/HexBuild/MmvArts.cs` 只读导出，绑定目标regulation、动作包及中文名称包SHA。生成器拒绝过期输入、冲突行、新增未审查战技，或已审核动作／公共攻击记录变化。
- `compat/mmv/arts.json` 保存104项取舍及7处HKS原函数指纹；`NRHEX_ARTS_DATA`只给MMV编译注入目标表，独立版默认使用原表，发行脚本显式固定原表。
- 5项目标表与新通知测试通过；独立版／MMV分别筛选45项Rust测试通过（其中包括相关名含arts的其他回归；1项无关偷心者原生夹具按默认忽略）。覆盖精确行为、主武器实例、广播标记、快照字段、连段、丢捡和生命周期。
- 4项HKS验证通过：157函数合并，5376内部片段、32圣杯瓶场景、26880原前缀差分；新增7处通知另验拥有／未拥有及左右手、使用／忙碌边界。
- 原生行为解析调用点检查及玩家装备发送／六槽序列化隔离执行通过；不等于真实网络到达和远端动作验收。

待实机验证：新武器首个战技、连续重铸、蓄力／持续循环取消、丢捡、以及双方更新后的动作／伤害同步。以下“接入”是静态审核和实现范围，不声称所有战技跨武器均已实测。
