# 强化【标记】

0.17.220。文案「你的滑铲可以踢飞小型敌人」，仅铁眼可抽取。稳定拥有者95004200、历史位39，保留已退役调香师95004100的历史位38。共38项注册能力，禁用的恶魔召唤仍不进入抽取；历史仍使用5字节。

原生SwordArtsParam 106是箭步上挑，AtkParam_Pc 300000290的dmgLevel为9（UPPER），300000295为3。原生标记600000110的dmgLevel为1，BehaviorParam_PC 600000110引用同一攻击，PlayerCommonParam.markingAtkParamId同样指向600000110。600000120为铁眼毒伤遗物的独立追加攻击，冲击等级0，本能力不改变它。原始攻击参数行全部保留，不增加伤害、削韧、标记时长、冷却或额外攻击。

复用已经安装的E70350七参数命中构建包装器，在原构建完成后确认context[0]恰为本机角色，再检查context+8攻击编号、+C表种类1及拥有者。只有标记命中把hit+24改为9；此前的大力映射照常执行，最终标记上挑固定为9，未拥有此能力时大力原效果不变。普通攻击不会额外查询本能力的拥有状态。不按武器池倾向筛选或在运行时重复限制职业；抽取、刷新按铁眼角色资格过滤，因此转职遗物不改变本技艺的专属资格。

修改发生在缓存／网络复制之前，输入在此命中生命周期内保留，不在派发后改回。接收者仍沿原生43A170读取hit+24并调用虚方法映射，得到hit+2B6；敌人的原生霸体和受击反应规则不改。因此不能击飞的敌人不会被强行修改动作。联机只在本机来源构建时改值，远端副本不重复提升；实际传输与各类敌人的动作仍需实机验收。
