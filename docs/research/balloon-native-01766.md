# 气球的原生伤害入口

## 调用链与修改范围

当前EXE SHA256：`9545e8732919bb6a63904cb73223641b3c4f9a67869be5722612acca413e8b3a`。

`E70350`复制攻击上下文，调用`6C2DD0`生成攻击分量。来源为角色（原生类型1）时，该函数调用虚表`+360`；来源为弹丸（类型3）时先解析`+B0`所属角色句柄，再调用所属角色的同一虚函数。玩家虚表`2C307F8 +360`对应`668670`，随后进入`6C3200`。不能把通用后备函数`6C2EB0`当成玩家路径。

气球私有攻击`AtkParam_Pc 95001760`在构造入口将单次攻击上下文`+F8`置1，选择原生固定攻击分支，不使用武器面板。该字段不是共享参数或角色状态。`6C49BB`的`MOVD XMM8,ECX`之前，ECX持有基础物理攻击值，RDI持有当前攻击上下文；补丁只将ECX换成来源角色最大HP，重放原指令，再由`6C3200`应用原生基础攻击修正、`E70270`写入原生最终倍率、`439E80`处理目标防御／减伤／格挡。

最大HP保留触发时快照，并校验角色和属性模块身份。远端原生重建路径读取自身来源角色的最大HP，不读取全局“最后一个发射者”的伤害。构造后的原生命中数据继续供复制、缓存与网络流程使用。未知来源或失效句柄不作替换。

删除原`PhysicalBuffs`及原生伤害计算后的`hit+280`覆写。增益是否适用及何时缓存由原生处理；死亡时已失效的增益不再由Mod快照强行保留。普通物理分类、黄金冲击波、7号冲击力和发射／倒地去重机制不变，不更改角色阵营。
