# 亮剑自动加成与落地爆炸

亮剑基础百分比＝目标参数估算的原飞行距离（米），保留一位小数；无可比较飞行距离为 0%。伤害加成、咏唱减伤仍共用此值，回收倍率仍为基础百分比的两倍，并继续使用原生回收槽与原生高阶倍率。没有另行引入新的上限或修改回收公式。

`tools/build_sword_auto.py` 从目标 regulation 导出的 Magic / Bullet / AtkParam_Pc 和中文名称生成数据。独立版 160 个法术；MMV 当前 204 个法术。构建无需手填 CSV，也不读取用户排序后的研究表。已排序的研究表保留。以下是生成的只读核对表：

- [独立版自动加成](sword-auto-native.csv)
- [MMV 自动加成](sword-auto-mmv.csv)

独立版输出 `src/sword_map.rs`；MMV 以合并后参数为输入，输出 `work/compat/mmv/staged/sword_map.rs`，由 `NRHEX_SWORD_DATA` 编译到共享运行时。含百分比、攻击归属、根弹体及已核对的下坠名单。共享攻击 ID 保持取所属法术最小百分比的规则，回收光环的返程攻击仍保留映射，只有其射程跟踪被解除。

估算模型沿用射程研究中的分段速度、重力、标称寿命、水平地面和初始高度假设，不是原生引擎仿真。无飞行的直接攻击／恢复／增益与明确排除的创星雨当前为 0%。MMV 新法术使用自身参数，不能将独立版估值直接搬过去。融泥块按载体首次落地估算（本次约20%）；融泥漩按喷流最远外扩估算（约6.6%），回流和沿途 AOE 不累加，200米/秒的竖直探地预算不算400米射程。零寿命不是无限寿命。

## 幽影之地的实测校准（2026-10-25）

MMV Magic 2006680 的末段伤害弹体 210668009 原先按本行 `dist=999`，将初速15、范围内加速度120、最高速度45、寿命2秒积分成86.25米。未持有亮剑的两轮只读采样共取得55段完整生命周期：初速15，第二帧升至约17，后续保持约17；寿命结束前累计飞行33.43～33.72米。这里是弹体自身的累计飞行，不是施术者到目标的保证命中距离。

原生 `0x34FF64` 比较累计路程与实例 `+0x224`；所有补采样的该弹体实例阈值均为0，故起步一次范围内加速后即切到范围外加速度0。本次抽查的原生运动与追踪函数机器码与EXE一致。阈值为何初始化为0尚未完整追溯，因此不推广到其他MMV法术，也不假定所有子弹都继承根弹的dist。

估算器只对已核实的这一末段采用零阈值、60Hz及原生首帧不移动的分支，仍从当前速度、加速度、寿命参数计算，结果33.7米／33.7%而非手填加成。变更参数结构时校验失败，需重新核对。现场数据和分段汇总位于 `work/sword-range-export/shadow-validation.json`；探针只读，采样后已停止。修改生成快照不等于已替换运行中的DLL。

## 平滑下坠

海摩炮弹、熔岩球、滚烫熔岩、感受巨人火焰吧、授血，以及MMV融泥块的普通／蓄力载体，改为从出手起使用平滑抛射曲线。按目标参数初速、额外仰角，以及默认发射高度1.5米，求出正常平地瞄准约4米落地的重力。生成 `DROP_ARCS`，不手填每法术射程。实际出手俯仰保留，朝上瞄准、高处施放或地形较低都允许超出6米；没有6米处突然竖直折向或强制消失。

`0x34FF00` 原生速度更新后、位置及碰撞更新前，仅对已持有亮剑来源的名单实例写入这一帧的中点速度。保持初始水平速度大小及原生水平追踪方向；竖直速度连续随时间下降。两种原生积分方式都读取同一个中点速度，不直接改位置，不补寿命。未持有亮剑、普通投火及其他弹体不走这条分支。原生继续处理真实碰撞、落地爆炸、特效、范围和销毁。

模型以平地默认瞄准为校准条件，不能保证所有动画出手高度和地形上恰好4米。隔离测试验证30/60/120Hz下约4米落地、上抛超过6米、仍有前向速度、原生终末派生与有限寿命；场景碰撞仍为夹具，不能替代游戏实际碰撞或联机验收。

## 原生终末效果检查

生成器遍历两版全部法术的Magic/Bullet派生链，输出 `RANGE_ENDS`。对自由飞行到期后进入静止效果的段落，缩短至6米时进入原生状态3，保留原生派生条件和视觉交接，不按墙体碰撞处理。只有因亮剑提前结束的后续终末效果解除范围跟踪；普通自然派生不会因此全局解除限制。碰撞专用条件、同一弹体接续、探地高速组件与平滑抛射分别分类，不把所有HitBulletID都无条件放出。

恶神火焰保留原生引爆前摇及爆炸链。艾尔登流星的主弹各阶段经链路校验后共用原生终末爆炸，不会在6米处重新开始另一段主弹飞行。相迭光环在6米进入原生普通2秒／蓄力2.5秒停留，保留伤害频率与共享特效。旋流、米凯拉的光、虚幻小宇宙按水平6米转入原生探地后续链，不在空中直接产生地面效果。

更复杂的运动接续与沿途生成不会仅凭“有子弹”跳过阶段；完整排查清单见 `sword-end-effects.csv`。静态链路核对不等于每个法术都已实机验证。

### 本轮补充的定位和接续

责罚荆棘、拒绝的刺的前行定位在水平6米进入原生终点探地；沿途探地与末端荆棘链保留。岩块刀刃在水平6米开始原生两侧探地、升起与蓄力接续。远方之恢复通过已核对的210640000→210640001，在6米进入原生治疗效果，不直接删除治疗载体。

灵火吐息210702000/001的同步发射点位不代表贴身静止，纳入与既有龙息一致的实际运动计距；210702002的FollowType4尾段也纳入。米德拉的癫火210730000/007、神鸟羽毛210774000同样补入明确同步白名单。黑蛇Magic6908使用MMV的12407000～12408300地面火焰接续，13条实际HitBulletID边逐项校验后写入目标生成的FLIGHT_CONTINUATIONS，整条链共用最初水平起点；不能每跳重新获得6米。原有109条基础接续继续保留。

火焰雨2007810不按下落火焰寿命乘速度计距。根210781000/050是零速EmittePosType6定位器，当前目标dist为25。原生33E97E将生成描述符+184复制到组+4B4；344570类型6分支在344862读取此缓存，比较目标与来源的三维距离平方，超距进入原生来源位置回退。亮剑只在已确认持有来源的工厂调用期间将描述符范围上限置为6，原生复制后恢复输入；不改共享参数，不改云和落火高度。根的后续链解除飞行限制。自动基础加成和射程表采用当前参数召唤距离25米／25%，而非火焰下落距离。目标分支及复制指令已核对；输入恢复和拥有隔离已纳入夹具，实际云位置与联机仍待游戏测试。

全量静态排查命令：`python tools/audit_sword_end_effects.py`。覆盖独立版160项、MMV204项，输出每个已登记终末/周期派生的处理和证据边界。没有Magic/Bullet可见入口的动画逻辑不在此表保证范围内。

### 辉石指爪／繁指爪

MMV 2004500/2004510的普通、蓄力四条主链均由11段组成：6段运动与5段零速停顿交替。此前只有每一段自己的6米，停顿与重新加速导致距离预算重置。本次逐项校验HitBulletID、单段数量、跟随标志和生命期，将40条边加入目标FLIGHT_CONTINUATIONS；停顿段也保留原点，恢复前进后仍受同一三维6米范围约束。繁指爪最初的6颗弹体各自起算，不合并发射位置。原射程估算随之按完整接续链累计；追踪弯曲仍未纳入静态估算。原生隔离覆盖移动4米、停顿0.2秒、再移动2米及超距退场。

授血6310的两个九发投掷入口10631000/005纳入4米平滑下坠。落地后的10631001重力探地与10631002血焰区域解除额外计距，仍由原生碰撞和派生条件决定何时生效。爆散结晶已取消3米强制爆开和寿命补足，改用统一终末效果规则；自然寿命先到或提前碰撞时不强制继续飞至6米。

满月4360、暗月4361的终末爆炸10436001/10436101保留0.1加速度，但初速、速度上下限及重力均为0，不能仅凭非零加速度判定为飞行接续。生成器核对两条完整末端引用及静止约束后，将主体在6米处转入原生状态3，释放各自原生爆炸；不更改伤害、异常、半径或特效参数。生成器回归检查拒绝末端变成实际运动弹的情况；原生隔离检查6米处恰好生成一次爆炸、解除终末计距并完成清理。实际视觉与命中仍须游戏验收。
