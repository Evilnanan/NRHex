# 气球与强化【召唤灵魂】（0.17.33）

后续更正：0.17.36 的现场测试证实死亡后的效果发射被跳过，并纠正了灵魂描述符的字段解释。当前实现以 [现场诊断](new-hexes-live-fix-01736.md) 为准；下文保留当时记录。

当前版本按已核验的 EXE 与 regulation 指纹开发。构建、参数回读与隔离测试通过；这两个新海克斯尚未做游戏内或联机验收。

## 气球

拥有行 95001700：最大 HP 倍率 1.5，八类承伤倍率 1.3，突刺另乘 2，最终为 2.6。比例与现有减伤效果相乘。描述来源为 `docs/hexes.md`。

发射链复制原生 8630802 → 863080000 → 12641050 → 12064105，独立 ID 分别为 95001701、950017000、95001750、95001760。保留黄金冲击波 SFX、原半径／扩散及 7 号冲击力；取消原累计击杀条件与替换链。新爆炸允许施加于已阵亡玩家，并保留一秒发射窗口，不阻止死亡。

死亡入口 3DD3D0 在原生清理前保存最大 HP；HKS 的死亡、濒死和两种复活通知补足状态转换，原生 102100 濒死信号也受同一去重保护。一次倒地及其后的阵亡只触发一次，复活后重置。状态在倒地期间暂时清理效果时保留，角色或生命模块更换、实际失去拥有状态时清除。

独立攻击在原生伤害计算后、消费／网络复制前写入最大 HP 伤害。自己的爆炸使用触发时的快照，远端来源读取其同步最大 HP；保持原生已跳过计算的命中分支，不加入其他海克斯的攻击增幅。攻击本身禁止命中自己与友方。

## 强化【召唤灵魂】

拥有行 95001800；抽取池以当前角色 ID 6 限定复仇者。拥有掩码改用 32 位，以容纳第 17 项；旧球的 2730 组对应关系保持，新增组合追加至 4080 组。

死亡通知在原生清理前读取模型、NPC 与当前／备用 Think ID，仅保存这三个整数，不保存尸体指针。通过团队成员、三个家人槽与六个死灵槽的原生击杀者句柄，或持续伤害来源，判断团队击杀。强敌目录来自原生 BOSS 血条／共用血条事件与地图敌人绑定，并补充原生强敌标记；刷怪笼只接纳战斗成员，排除非战斗骑乘附件。新击杀覆盖上一只，复数敌人不会被作为整组储存；当时实现允许储存内容在灵魂消失后再次召唤；0.17.38 按用户反馈改为成功召唤即消耗，失败保留。

HKS 仅在 `ExecSummon` 的原生召回输入分支插入通知。三种家人有任意一只时不会触发。原生 `IsEnableSummonAct` 在三槽均为空时为 1，完整控制流模拟确认了这个值；没有按变量名称推断含义。普通召唤和切换家人分支未修改。

NPC 行私有复制到 95400000 起，原有行逐字段不变。清除卢恩、地图／敌人／强化奖励与锻体掉落，以及再次被死灵术选中的资格。原生 705200 仅在私有灵魂身上替换为 95001801，其余 AI／友方／白灵初始化保留；新行每秒扣 100/15% 最大 HP，采用原生整数 HP 和计时规则，不修改普通死灵术概率或普通灵魂寿命。最多一个本海克斯召出的存活灵魂；原生家人槽与被动死灵槽照常运作。

## 检查及待验收项

179 项代码测试通过，包括完整拥有组合、复仇者限制、倒地清理、独立灵魂、有效零模型／NPC ID，以及六参数创建和四参数联网载荷的模拟调用。当前 EXE 的 78 处签名均唯一且位于核验 RVA；五个 HKS 函数的 52 项输入／家人／拥有情况通过，逆向还原补丁可恢复输入。新增参数与文本均回读，旧参数行、旧球对应和其他资源保持。
