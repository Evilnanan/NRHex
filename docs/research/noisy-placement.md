# 吵闹鬼的同层落点与水平定位

0.17.269针对用户反馈的MMV普通地形中心主城地面→地下室落点问题，改用玩家正下方的有限地面探测。尚未在该地点游戏内验收。

## 调查依据

重新读取两版发行regulation 10350000，95001501→950015000→95001550～95001557的字段一致。八颗私有弹体与原生12482050～12482057仅攻击／子弹体ID不同。原生发射效果指定dummy232；MMV当前c0000模型中该挂点的局部坐标为约(0,0.00047,-1.62317)，不跟随附着骨骼。旧定位弹重力999、半径0.1、寿命1.5秒，且旧流程没有同层高度限制；水平偏移和贴地起点是风险因素，未以现场坐标捕获确认唯一根因。运行时的视觉放大只缩放矩阵基，不改变平移。

## 当前实现

`noisy_ground.rs`接入已有BulletMan根发射／工厂钩子，不新增原生hook，不改模型、参数或地图。只处理本机拥有吵闹鬼的私有根：直接弹体95001550，或尚未解析的行为950015000；子弹体、原生遗物、其他玩家和其他攻击继续原流程。

实际发射时读原生角色位置，从脚下上方0.5米，以半径0.05米的原生球扫向下探测1.25米。使用原生召唤定位的几何管理器及0x79碰撞掩码。仅接受向上法线、有效命中，以及相对脚下高度-0.75～+0.25米内的支撑面；没有合适地面就取消本次生成并解除待生成状态，下次标记可重试，不向下层或附近另选落点。

注意原生DB04A0的第九输出是`start + fraction * motion`，即扫掠球中心，不能当成表面接触点。实现按半径和法线求出玩家X/Z所在的接触平面高度，再抬高0.02米避免贴面闪烁。X/Z严格保留玩家坐标，斜坡也不添加水平偏移。

探测代替不可见飞行定位弹，直接接入95001551静止准备阶段。后续原生准备、4秒蓄力、0.8秒爆发前摇、伤害、叠层、散落和清理链保留。这里只修正初始整团熔岩的位置；爆发后的原生散落轨迹保持，不能将本次检查扩展为所有残留小熔岩都不会跨层。

发射使用同步借用的0x110字节描述符副本，清除挂点及实体目标，设置独立发射／固定矩阵位，保留归属、伤害相关字段及网络位。现有工厂入口通过一次性TLS作用域恢复解析后的世界矩阵，避免原生重新读取dummy；嵌套的其他发射隔离，后续子阶段不反复拉回玩家位置。副本不跨帧保存，不额外保留或释放原输入的引用。

原生35A460返回输出指针，失败时输出ID=-1；35DA70的无有效弹体错误码为3。取消沿用这组输出语义。35A460随后调用33E140序列化发射描述符，包含新的弹体ID、姿态和标志；接收端沿原生网络路径使用该位置，不根据接收端玩家位置重新探测。

## 验证边界

常规测试覆盖精确X/Z、平地与斜坡高度、下层／墙面／无效输出拒绝、原始描述符与引用字段保持、输出返回约定、工厂一次性作用域和嵌套隔离，以及原有叠层、清理和失败后重试。

原生隔离测试从已校验SHA256的目标EXE提取DB0B80适配器与345ED0固定矩阵读取器。底层几何求交使用上下两层可控夹具，验证12参数ABI、上下层选择、无地面拒绝和固定矩阵。它没有执行主城真实Havok碰撞，也不代表游戏内或联机验收。

两版DLL重新构建；发行资产和INI保持逐文件哈希不变。测试时重点复查主城同一位置、台阶、斜坡、地下室内，以及角色离开生成点后熔岩仍留在原处。
