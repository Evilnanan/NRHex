# MMV 追踪者钩爪出血修复

原版词条 `AttachEffectParam 6500000` 赋予 `SpEffectParam 7500000`，
对应动作条件 `stateInfo=2035`。`a900.tae` 的 500000／505000 动作保留
带该条件的 judge 6030；500005／505005 使用 judge 6035。

原版 judge 6030 经 `BehaviorParam_PC 600000030` 指向同 ID 的
`AtkParam_Pc`，附加 `7500001`（基础出血累积 60）；回拉段使用
`600000035 → 7500002`（55）。两个出血攻击的异常补正均为 100%。
当前 MMV 删除了射出段的行为和攻击记录，但保留动作引用和出血效果；
MA 的通常三方合并会保留 MMV 的删除，因此也缺失这两条记录。
扫描全部玩家攻击记录确认 MMV 没有把 `7500001` 转移给另一条攻击。

`MmvWylderBleed.Restore` 在 MMV 参数合并后，从当前受版本校验的原版参数
补回这两条记录。它核对地面／空中动作的命中窗口及词条条件、两条出血效果和
回拉段参数。已有相同记录时不重复添加；已有不同记录或链路改变时拒绝修改。
编辑器行名允许不同，实际参数字段仍完整核对，已有名称不会被改写。

单独刷新本地合并包可用 `HexBuild --mmv-wylder-bleed-stage <input-mod> <output>`，
输出目录必须与输入分开。输出回读检查只增加两条原版记录，其余行、顺序、
容器成员和动画输入保持不变，并验证重复执行不再修改。

这是资源修复，不需要新的运行时钩子，不改变回拉段、词条抽取或出血数值。
两段各命中一次的基础累积恢复为 60＋55；实际出血次数仍取决于命中、抗性及衰减。
参数回读和合并验证不能替代游戏内地面／空中施放及联机测试。

本次验证：HexBuild 编译通过；本地 MMV 参数补丁的两条新增记录、其余内容保留、
序列化回读及幂等检查通过；`--mmv-stage-safe` 完整参数／文本合并通过并回读
5 个输出文件。本地 MMV 参数包已应用单独补丁，未用部分合并预览覆盖整套资源。
