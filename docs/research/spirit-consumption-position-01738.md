# 灵魂消耗与出生位置（0.17.38）

用户确认 0.17.37 已能召唤；发现消失后可重复召唤、出生位置与角色重合。此反馈不扩大为持续扣血、友军 AI 或联机验收。

`Spirits::created` 只在有效句柄时清空储存与待处理召回，记录在场句柄。无效创建不消耗，家人在场／倒地／满槽仍不触发。`finished` 只清在场记录，后续新团队击杀仍可储存。私有灵魂死亡本来就被 record_soul 排除，不会重新储存自身。

沿用原生 391DC0 的 3CEB20 朝向 getter（Chr +60 → 39BBC0 → ChrModules +68 → 465720），第二分量为弧度 yaw；新增完整入口签名。出生位置沿角色局部 -Z 前移5米：X -= sin(yaw)*5，Z -= cos(yaw)*5，保留高度。方向约定与现有刷怪笼朝向计算一致。生成前做有限值检查、世界转地图坐标；原生槽 +20 世界位置、+30 朝向、+34 地图、+38 地图位置与 3D7130 瞬移及 1Bh 消息一致。地形避障未新增。

187项 Rust 测试通过，新增成功消耗／死亡后不可重复召唤、失败重试、四向位置检查。原生接口模拟使用非零 yaw 和非恒等世界到地图转换，检查槽、瞬移及网络载荷。实际游戏位置、消耗及双人视角待验收。
