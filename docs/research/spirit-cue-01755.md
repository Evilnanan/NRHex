# 0.17.55：收集灵魂的尸体白雾

用户反馈成功召唤出已击败的刷怪笼 BOSS，但看不到收集白雾，原生 BOSS 似乎也有同样表现。用户最终选择先修正尸体显示，暂不改回角色自身。

原实现从 SpEffectVfxParam 8500501 复制收集视觉行 95001803，改为原生死灵术白雾 461351、身体挂点 220。该模板的 `isVisibleDeadChr` 是 0。Smithbox 当前 NR 参数定义将此位描述为“开启时尸体也显示 VFX”。灵魂收集在死亡回调执行，白雾又在原生死亡处理后附加，默认不显示尸体与这个用途直接冲突。

收集效果 95001802 已有 `dontDeleteOnDead=1`，但“效果不因死亡移除”和“视觉在尸体上显示”是两个不同的开关。只保留效果不能保证看得到。

本次只将私有视觉行 95001803 的 `isVisibleDeadChr` 改为 1，并同步完整构建入口。不更换特效、挂点、目标、1.5 秒持续时间或灵魂收集规则；没有更改任何原生视觉行。仍只在成功储存／以更高最大 HP 覆盖储存时播放。

当前安装包回读检查确认开关从 0 变为 1，其他字段、行与参数表保持不变。DLL 重构建仅用于更新包版本，运行逻辑未变。实际尸体显隐、挂点大小、特殊死亡消失以及联机画面仍需游戏测试；未启动游戏。
