# 结晶外壳隐藏弹刀，0.17.30

用户要求外壳被敌人攻击击破时出现大盾弹刀，仅限能弹刀的攻击，游戏说明不增加此效果。中文文案继续以用户编辑的 `docs/hexes.md` 为准。

原生 `EquipParamWeapon 32000000` 的类型69为大盾，`guardBaseRepel=70`；盾牌其他变体有80，本次使用常规70。`guardLevel=4` 是持盾者的防御动作分类，不能当弹刀强度。原生439D50按防御弹刀强度与攻击强度比较，攻击强度取命中+2C与攻击者效果查询507950中的较大值，写入+2A8／+2AC；防御强度大于等于攻击强度时置+2BE。结晶原有43D5EE入口在这次比较之后、实际HP扣除之前。

只有原状态机实际消耗外壳并设置HP免疫位+2C3 bit1后，才尝试隐藏反应。先释放外壳锁，再核对原生R12来源为有效ChrIns、与命中+228的实际来源相同、来源伤害模块+8指回该角色，排除弹体、间接攻击及自身。沿用已结算的攻击强度，超过70、原生命中取消、原生防御击破、无正伤害输入或已有弹刀结果都不额外触发。

取0x2C8字节的栈上命中副本，只为副本设置+2BE和防御强度70，通过攻击者modules+90的原生436E50提交弹刀。保留原武器分类+122及原生动作选择1000／1003／1008／1009／1010、反应模块和后续通知路径，不硬编码NPC动画。原命中、HP免疫、伤害、防御状态及正常通知结果不被副本覆盖；436E50独立于HP消费者，+2C3的免疫不阻止该函数弹刀。原有40秒冷却、图标和VFX未改。新入口受当前EXE哈希和第57个特征码保护，不新增运行时诊断。

在私有PE镜像执行439D50与436E50：32项攻击基础／效果强度比较、30项武器分类／取消／击破／无伤害／HP免疫场景通过。对象身份、效果查询、方向句柄、模块查询及动作／通知消费者用受控桩替换，比较、原生动作选择与取消守卫保留原始机器码；这些隔离执行不能当实机弹刀或联机验收。
