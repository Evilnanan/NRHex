# MMV 刷怪笼适配

2026-10-26。仅适配包；MMV 原目录、独立版、配置与群友版不变。

## 内容与边界

- 原有 50 组保留，追加 59 组，总计 109 组。新增 95 个角色定义（含随从、坐骑及希斯断尾），每张监牢定义总数 179。
- 名单见 `compat/mmv/cage-encounters.json`。以真实 MMV 场景中的 HUD/BGM 初始化及演员绑定为依据，不按 `npcType=1` 或名称包含 Boss 自动入池。
- 纳入腐败树灵、腐败化身、死之骑士、火焰骑士、黑骑士、神兽／神鸟战士、灵火龙、冰龙、腐败龙、科尔维亚骑士、白龙希斯、怨恨之鬼、蝎子纳吉卡等。
- 排除守夜专用版本；同一模型存在有效野外版时使用野外版。已有同类遭遇及仅数值／禁飞版本不重复加入。仅在未使用模板里出现、未找到实际野外／监牢遭遇绑定的定义没有凭空启用。
- 原生组合保留；米兰达幼株、血怪随从、坐骑与尾巴不单独成为抽取项，也不计入主 BOSS 血条／收魂资格。

## 运行机制

`MmvCages.Stage` 在完成原有 MMV 合并后追加地图和事件，复用 `CageEncounters` 的出生、战斗、HUD、死亡、联机及 `CageMusic` 事件生成器，再重定位私有 ID。原 50 组事件不变，只替换抽取器并添加新事件初始化。

- 新 NPC/Think：95300200–95300294；实际模型来自源 MSB。
- 角色实体：各监牢前缀 +9200 起；生成器为角色 −5200；生成区 +4200 起；奖励实体组 +6000 起。检查身份冲突。
- 不能延伸旧的 `7500+choice` 等 50 项数组：第 51 项会撞上冷却标志。新抽取器使用独立连续的本地抽签区，再发布唯一共享 choice ON；不广播先清空再选择，保留已验证的联机包顺序修复。
- 所有新增状态都放入引擎已分配的 7xxx 事件标志区，通过扫描合并后的原有事件／奖励占用来分配。新遭遇共享一对变异决策标志；每张监牢仅一组活动遭遇，结束前清除；延迟清理不再访问这对共享标志。每组的 choice/cooling/reward、每角色的 shown/dead 保持独立。
- `cage_data.rs` 与资源同源生成；`cage_catalog::npc` 同时用于预创建排除、生成器识别和深夜变异。新奖励组纳入按需创建后的原生 TeamFight 重新绑定。
- 每组复用塔楼两武器＋一锻体球的 repeatable TeamFight。新 NPC 的单体奖励表引用移除，防止与组奖励重复；保留原始卢恩和战斗参数，使用原生多人倍率的本地校正版。
- 坐骑保留 Riding 配对，使用现有的原生实体解析／骑乘恢复。希斯尾巴最初隐藏，复用 MMV `1038102220` 的部位破坏、断尾动作及相对定位；补上所选遭遇／角色就绪和结束条件，支持重复抽取。
- 每组使用自身 MMV 原生 BGM 及名称；复数只在中心生成一个大黑雾，不强制未知模型执行未经核对的登场动画。
- 灵魂导出后置到刷怪笼追加之后，读取最终 overlay 地图／事件。95 个来源对应的收魂私有 ID 已追加注册，旧 ID 不重排。
