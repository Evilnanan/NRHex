# 武器接触与亮剑例外（0.17.357）

冰镇果汁追踪、引雷主动触发、大力采用 `weapon_contact` 的共同来源筛选，保留各自的触发时机和目标规则。未改变原生攻击分类，也未改亮剑射程、回血或伤害公式。

## 来源规则

- 普通武器：直接来源为施术者角色，原生攻击类别130存在且105不存在。包含符合该分类的武器接触战技；不把持有武器时生成的箭、剑气等弹体视为武器直接接触。
- 法术：当前构建的亮剑攻击映射包含该攻击，且本人实际拥有亮剑。无需法术带130近战标记；0%亮剑距离加成仍是已识别法术。原生使用类型3/4或已映射法术不会从普通武器分支绕过拥有检查。
- 未映射法术保持拒绝；独立版与MMV版分别使用各自构建的法术目录。自定义触发伤害不因来源玩家持有亮剑就自动获得例外。

原生E70350构造末尾已经完成类别复制：E7065E～E70674将两段16字节写到命中结构+124/+134，使用类型写到+122。构造阶段尚不能依赖+228，使用context[0]与本机角色匹配；接触阶段则使用原生填好的+228判别直接来源。原生构造类别复制的隔离测试核对EXE哈希和机器码，再运行真实复制指令。

## 使用者差异

| 功能 | 时机及附加条件 |
| --- | --- |
| 冰镇果汁 | 原生已接受命中通知；结算记录+280为正，目标不是本人或队友，当前风暴仍处于随身阶段。首次命中转追踪并刷新为3秒。 |
| 引雷 | 原生已接受命中通知；敌人的+280为正，或倒地队友有原生救援输出，且本人满充。取消原6米触发门槛；受击漏电规则、已标记目标继续累计规则保持。 |
| 大力 | 0.17.358起，普通武器和亮剑法术统一在新鲜攻击构造完成后设置冲击力及显式覆盖编号，接收重建不再提升；取代0.17.357的法术派发作用域。网络编码修复及验证边界见[冲击力传输调查](impact-transport.md)。 |

大力不能等待HP伤害确定后再改冲击力，否则会错过受击动作选择。因此统一的是攻击来源，不是把三者强行放进同一回调。大力继续排除PC攻击600000120的附毒判定，防止0→1覆盖滑铲已排队的击飞；滑铲主体仍由其自己的后续规则决定冲击力。大力原先允许亮剑下5米内普通箭矢、弩矢及战技弹丸的特殊分支已移除。

## 验证边界

独立版579项、MMV版580项常规测试通过；两套均有44项需单独环境的测试默认忽略。另外单独执行并通过MMV原生类别复制及亮剑筛选、滑铲／大力构造与原生冲击力复制、引雷快照与实际outgoing回调三项隔离测试。后者验证60米接触点的有效近战救援仍能消耗电量，非近战分类不消耗。隔离环境只执行所需原生片段，其他依赖使用夹具，不等同于游戏或双人验收。
