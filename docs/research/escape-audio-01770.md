# 逃跑计划的重演音效加载

用户实测：追踪者在训练场和远征均能看到逃跑计划特效，远征中加速、减伤正常，但听不到训练场中的声音。此前关于0.2秒视觉状态寿命的推测未证实，本次未改动视觉参数或持续时间。

当前EXE 1.3.3.0、regulation 10350000。原生Bullet 30903000的特效460820含NodeAudio 407000，对应Wwise事件`Play_s000407000`（ID 676254778）；事件位于`sd/hero04.bnk`，不在`cs_main`或`cs_smain`。特效画面在公共FXR中，声音却依赖女爵音效包。

原生场景音效收集器RVA EF8B20收集本地角色／队友的职业ID。特定场景分支显式加入4（女爵）和6（复仇者），与训练场可听、追踪者远征不可听的反馈一致。它使用EED260将非零职业ID插入唯一集合，随后把集合转为场景持有列表（+2E8/+2F0），通过F14360请求`hero%02d`音效包；EF1750检查加载就绪，原生场景清理负责释放。EED260的四个直接调用点均位于该收集器。

`src/hero_audio.rs`在原生插入非零合法职业ID后，额外通过同一个原生函数插入4，保留原调用返回值。重复ID由原生集合去重；DLL未启用、零ID、女爵和未知ID保留原行为。音效包在场景准备时加载，覆盖之后才领取逃跑计划的情况。此修改增加原生女爵音效包的驻留，不复制声音文件，也不改角色职业或视觉参数。

验证：Rust模拟原生唯一集合与ABI返回值；`verify_hero_audio.py`核对当前EXE的四处调用及实际BNK事件归属；全部入口签名扫描。以上均为构建／静态／隔离测试，远征声音与联机仍待实测。
