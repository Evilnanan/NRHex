# 亮剑躯干距离起点

用户反馈：上方敌人难以进入亮剑的有效距离。当前 `position` 读取角色物理模块 `+0x70` 的世界坐标，这个坐标是脚下基点；`sword_hit_distance` 此前直接把该点与命中结构 `+0x1F0` 的世界接触点比较。即使没有明显水平距离，角色自身高度也会占用一部分有效半径。

本次将亮剑自己的起点定义为脚下世界坐标上方1米，作为固定的躯干参照点。`sword::hit_distance` 只平移 Y 轴后计算三维欧氏距离。它是距离判定的设计选择，并非读取动画骨骼的精确胸部挂点。角色跳跃与位置变化仍跟随原生物理坐标；弯腰等姿态不会让起点来回晃动。

伤害失效与吸血条件继续调用同一个 `sword_hit_distance`，有效半径保持4米。命中点仍取本地或联网命中结构的真实接触点，不改成敌人基点、不使用会随弹丸移动的发射点，也不忽略高度。世界坐标、无效空间模块和非有限数据仍按原有规则处理。未修改参数、动作、特效或用户文案。

检查包含：水平3.8米、脚上方2米的接触点由失效变为有效；躯干同高的4米边界与超界；上下高度仍有限制；实际运行时入口在模拟角色模块、命中结构中读取正确的接触点；缺失角色／命中／空间数据与NaN拒绝。发行包仅DLL变化，两个ME3配置与群友版无快捷键条件另外检查。本次未启动游戏，实机与联机仍待验证。
