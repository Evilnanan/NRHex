# 百般武艺：普通箭与拉塔恩骤雨

2026-11-15，0.17.344；MMV 2.1.9 Beta2-Hotfix1。

用户报告小弓有动作、没有箭雨。只读现场装备为骸骨弓 40500000、普通箭 50000000，右手共持。未中断当前出征。

## 已核对的缺口

- 原生骤雨动作组 769 的 44560 / 44565 发射事件使用判定 881 / 886。原生解析器 `668B30` 根据传入来源查装备的 behavior variation；这两条是弹药行为，不是普通战技的 3000 段武器行为。
- 普通箭行为 105000881 指向 20000081，它是没有后继链的普通多箭弹体；105000886 不存在。
- 大箭行为 105100881 / 105100886 分别生成 20100081→82→83→84 和 20100086→87→88→89，包含空中载体及最终箭雨。5101 系列另有原生链，必须保留。
- 旧百般武艺只替换普通武器战技行为；即使扩大判定范围，沿弹药来源查找重铸武器实例也查不到弓的战技。

## 修改边界

仍先执行原生五参数解析器，保留其副作用。仅持有百般武艺、实际共持弓且该实例重铸为 1169 时，针对 881 / 886 将缺失或不匹配的弹药行为替换为 105100 系列。原生 105100 / 105101 返回值不变；其他战技和普通射击不改。不改参数、弹药库存或发射位置。

此版本曾按左手共持状态2、右手3查询实例；0.17.346的现场采样证明射箭时装备持握可保持1，这个前置条件不成立。已改为从原生传入弹药来源-6／-5恢复发射手-2／-1，详见 `arts-compatibility-audit.md` 的后续更正。联机实例继续使用已有的战技同步读取路径。

## 验证边界

检查了当前 EXE 解析器签名、武器来源接口、两个大箭链的完整性及最终攻击／视觉引用；551项常规测试、26项MMV百般武艺测试通过，覆盖限定条件、双手映射、保留两种原生大箭及其他弓战技。用户授权后仅更新MMV测试版DLL并重启，核对加载路径、DLL哈希、0.17.344日志及主更新／战技行为／弹体钩子。箭雨效果尚待游戏内验证，不据此声称联机或最终伤害已经验证。
