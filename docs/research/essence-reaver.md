# 夺萃之镰的累计专注值

0.17.229当前图标为21292／22292，奖励物品图标20292；永久能力的额外Buff栏图标显示仍关闭。以下早期单图标说明不代表当前显示开关。

当前实现保持 `1.01^击杀数`，不创建逐杀增益，也不显示层数。图标来自海克斯本身的 20292；击杀数仍以至多四个不可见的本地保存记录编码。

原生参照是复仇者的 7500501～7500550：category 204、不同优先级的固定档位、每档增加 0.75% 专注值上限。它不是无限叠加同一条增益，不能直接替代本海克斯的无限乘算成长。20492 则出现在其他限时专注值效果中。

当前游戏 EXE SHA256：`9545e8732919bb6a63904cb73223641b3c4f9a67869be5722612acca413e8b3a`。

- `0x5103d0` 从单个 SpEffect 的参数偏移 `0x14` 读取 `maxMpRate`，处理原生排除标志和条件修正。
- `0x50c230(manager, mode) -> float` 遍历有效效果节点，调用上述函数并乘算。这是新扩展点：先运行原函数，仅对持有海克斯的本地角色乘入累计倍率；其他角色、其他增益仍走原逻辑。
- 属性重算处 `0x428da6` 和 `0x428de2` 调用该查询，分别更新最大专注值和用于原生差额处理的值；原生初始化和基础值查询也使用同一入口。不直接修改当前专注值或共享参数。
- `0x7deb30` 汇总图标；永久效果需要 `displayIconForPermamentEffect`。海克斯本体打开此标志即可保留单个图标，无须添加额外显示节点。

构建移除 95002902 的逐杀增益参数，运行时代码不再创建或兼容清理旧层。击杀资格、保存记录和远征重置事件保持原有逻辑。

验证包括原生 FP 聚合函数的隔离执行、单图标聚合、运行时击杀／复活／重载／重置模拟，以及本地与其他角色隔离。实机数值和联机显示仍需游戏测试。
