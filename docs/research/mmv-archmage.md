# MMV 大法师适配

2026-10-26；Mayhem Augments 0.17.254。只更新 MMV 测试版 DLL，原 MMV、合并资源、现有配置、独立版和群友版均不变。

## 分类与候选

根因是共享运行时以前只编译原生 178 条类型记录和 151 种随机候选。MMV 原法术仍可走副槽免耗，但新增法术无法通过 `kind` 完成触媒识别、使用后入队及同类随机。

生成器现从实际目标 regulation 的 Magic.ezStateBehaviorType 识别全部 0／1 类型；MagicTableParam.chanceWeight > 0 且对应 Magic 存在、不是 isEnchant/isShieldEnchant 的法术进入随机池。不以 NT 禁用位判断可用性，不以弹体／直接伤害作为资格，不套用回响的排除名单。与原版规则一样，同类候选去重、等概率且不重复当前法术；不按照原生掉落权重加权。

当前识别 226 条（原有178＋新增48）；随机池192种（原有151＋新增41），其中魔法78、祷告114。原有法术分类与151个候选均保留；9种原附魔继续排除。新增的黄金树庇佑、卡利亚恩惠、发狂扩散及4条无名称内部记录没有正权重，只识别、不随机。正权重表还引用了不存在的625、685、4140，沿用独立版规则跳过并在报告列出，不制造新法术。

## 实现与更新

`Archmage.ExportTarget` 只读目标包并导出两张表的必要字段、路径和 regulation SHA；Python 生成器核对路径／哈希，拒绝过期导出或相同 Magic ID 的冲突分类。`tools/mmv_build.py` 每次从新合并包重新导出，记录生成表指纹，并为 dist／community 注入同一目标表。build.rs 默认仍取独立版表，发行构建显式固定原生表以防继承 MMV 环境变量。

无需新增钩子或改动作脚本。已核对安装的 MMV HKS 保留全部34个原生施法通知（主／副槽、左右手、连发及蓄力释放）；额外的无效施法／恢复／骑乘入口不冒充副槽施放。共享 `Archmage` 继续只重铸槽1，按触媒实例身份保存，死亡取消待重铸但保留已有结果，跨出征清空；序列化只改公开装备快照的副槽。联机仍走现有设备广播，不新增协议。

## 验证

- 5项生成器／安装HKS检查：类型、双附魔标志、零权重、重复掉落行、缺失引用、冲突分类、全部新增内容和34回调。
- 独立表及MMV表分别15项 Rust 大法师测试通过。新增遍历全部分类及每个同类候选，验证连锁后随机、副槽快照仅改+18、dirty广播标记、丢捡身份、死亡和新局重置。
- 原生法术槽 getter 隔离执行、左右手／主副槽选择、战技旁路、24组耗蓝和持续耗蓝调用点检查通过。4项MMV构建流程测试通过。
- MMV release DLL 构建通过。输入为当前安装参数，部署只替换DLL；资源／配置及原MMV指纹逐项核对。

以上不等于游戏内全部新法术或双人远端动作验收。待测试新增副法术连续施放后随机、主槽保持、免蓝，以及双方更新后的装备显示和施法效果。
