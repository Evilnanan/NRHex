# 别停止咏唱：完成蓄力回精力（0.17.219）

当前文案：魔法、祷告完成蓄力时，回复30点精力值。替代原先蓄力期间每秒回复30点，不叠加旧效果；抽取资格不改。

## 触发依据

原生六个左右手、一至三段 MagicFire 更新回调，在 MagicCommonFunction 的中断判断及100610窗口内的松手／不可施法判断之后执行通知。旧补丁额外要求100610存在，因而只能观察蓄力过程。新补丁只移除这个附加门控，保留 IsChargeMagic、非 CheckIfHoldMagic、IndexMagicSlot 不为2以及原生所有取消分支。

原生 IsChargeMagic 通过45011动作是否存在判断可蓄力。帚星a402的45010／45020／45030中100610分别从0持续至20/30、32/30、32/30秒；提前松手进入45011／45021／45031取消释放动作，这些动作没有100610，且使用未注入通知的Cancel回调。正常Fire回调中观察到100610由有变无，才视为蓄力完成，而不是仅凭全局效果消失触发。不同动画速度沿原生窗口推进，不使用固定计时。

Rust要求先收到有效蓄力通知，再在连续有效回调中看到窗口结束；完成后立即消耗一次资格。未蓄力、反复完成通知、无通知的取消／中断、能力丢失、死亡／濒死／救援或角色属性对象切换不保留回复资格。正常下一次蓄力重新准备。满精力也会消耗这次资格并播放反馈，不储存溢出。

回复仍调用原生4261D0(stats,30,false)，由427F00限制精力上限，不直接写精力字段。操作在状态锁释放后执行，特效添加不持有Chant锁。

## 捕猎反馈

原生野兽的捕猎8970054使用VFX73110，初始特效674895、挂点220，持续效果301202，原生持续0.3秒。新建纯视觉效果95002001，引用同一VFX并持续0.3秒；不直接施加8970054，因此没有其100点恢复、友方目标设置或8970053的15秒恢复速度增益。无需修改特效资源。回复和反馈仅在一次完成通知被接受时执行。
